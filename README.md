# Team Builder

Live static version of Team Builder for GitHub Pages.

## What it is

A browser-first org design tool that lets you:
- add duties
- add people with strengths
- create role cards
- drag duties and people into roles
- rebalance workload with sliders
- draw reporting lines
- persist changes in browser localStorage

## Honest limits

This Pages build is static:
- no backend
- no multi-user sync
- no shared database
- no auth

That tradeoff is deliberate so the first handoff is actually live and free.
